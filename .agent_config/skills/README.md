# Skills

Each skill is a directory containing a `SKILL.md` and an optional `references/` folder. Folder structure and frontmatter default to Cursor's conventions as the most verbose format — the sync step restructures as needed for each platform.

```
skills/
  my-skill/
    SKILL.md          # Frontmatter + instructions
    references/
      extra.md        # Appended to the compiled skill file
```
